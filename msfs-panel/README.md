# Optional MSFS toolbar wrapper

AeroSlate no longer depends on an in-simulator panel for Navigraph access. The official Navigraph and SimBrief websites are presented through AeroSlate's native provider workspaces.

This folder is retained only as an optional pattern for showing the hosted AeroSlate interface in an MSFS toolbar panel. Live telemetry and OOOI use `bridge/aeroslate_bridge.py`; no direct Navigraph Charts API credentials or chart-image endpoints are included.
